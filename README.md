1. AI English Correction

User type kare:

Hey bro, I am not able to understand this things.

AI suggest kare:

Hey bro, I am not able to understand these things.

- Correct grammar
- Fix spelling
- Improve sentence structure
- Apply correction before sending

2. AI Rewrite & Tone

Ek hi message ko different styles mein rewrite karna:

- Friendly
- Professional
- Polite
- Short and clear
  User ko final message send karne se pehle preview aur edit karne ka option do.

3. Hinglish to English

Example:

Mujhe samajh nahi aa raha ki kya karu.

AI suggestion:

I don't understand what I should do.

Ye feature Indian users ke liye particularly useful ho sakta hai.
